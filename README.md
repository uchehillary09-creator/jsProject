Neyduh’s Fashion Hub

A luxury fashion storefront and digital atelier for a Lagos-based fashion house specializing in ready-to-wear, bespoke tailoring, and bridal couture.

Features

• Interactive Catalog: Multi-category store (Women, Men, Bridal, Streetwear) with live NGN pricing and filters.
• Cart & Wishlist State: Client-side tracking across pages using Vanilla JavaScript.
• Studio Concierge: Direct WhatsApp API integration and custom booking forms for private fittings.
• Editorial UI: Automated hero image slider and responsive grid layouts.

Tech Stack

• Frontend: HTML5, CSS3 (Flexbox/Grid), Vanilla JavaScript
• Deployment: Vercel
